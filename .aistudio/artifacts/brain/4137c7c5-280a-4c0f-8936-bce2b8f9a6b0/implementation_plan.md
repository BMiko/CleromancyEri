# แผนการพัฒนาแอปดูดวง Cleromancy: ศิลาและลูกเต๋าพยากรณ์ชะตา (Astragalomancy & Sacred Runes)

แอปพลิเคชันดูดวงเสี่ยงทายโบราณ Cleromancy แบบเสมือนจริง ผสานศาสตร์การทอยลูกเต๋าพยากรณ์โบราณ (Astragalomancy) และการเหวี่ยงหินสลักอักษรรูนศักดิ์สิทธิ์ (Elder Futhark Runestones) บนแท่นบูชาหินในถ้ำลึกลับ พร้อมแสงเทียนสลัว ละอองเวทมนตร์ประกายทอง และการวิเคราะห์คำทำนายชะตาเจาะลึกสดด้วย Gemini AI ตามคำถามของผู้ใช้ พร้อมบันทึกคัมภีร์ประวัติการทำนาย

## User Review & Critical Decisions

> [!IMPORTANT]
> สรุปทิศทางที่ผู้ใช้เลือกในรอบการสอบถาม (Phase 1 Clarifications) เพื่อกำหนดทิศทางการสร้าง:

- **อุปกรณ์ทำนายหลัก (Confirmed)**: ลูกเต๋าพยากรณ์โบราณ (Astragalomancy 3 ลูกเต๋านำโชค/ธาตุ/ชะตา) และหินสลักอักษรรูนศักดิ์สิทธิ์ (Sacred Elder Futhark Runes)
- **ระบบวิเคราะห์คำทำนาย (Confirmed)**: AI พยากรณ์เจาะลึกสดตามคำถามที่ผู้ใช้พิมพ์ถาม โดยผสานเข้ากับค่าลูกเต๋า, ธาตุประจำหิน, และสัญลักษณ์รูนที่ทอยได้จริง
- **บรรยากาศและธีมภาพ (Confirmed)**: ถ้ำหินศักดิ์สิทธิ์ แสงเทียนสลัว โทนดำออบซิเดียนและทองประกายเวทมนตร์ (Mystic Obsidian & Flickering Candlelight)
- **ระบบสำรอง (Graceful Offline / Fallback)**: มีฐานข้อมูลตำราพยากรณ์โบราณ (Ancient Grimoire Interpretation) ฝังในระบบทันที หากไม่มีเครือข่ายหรือขณะ AI กำลังประมวลผล

## 1. Overview & Core Concept

### What It Does
**Cleromancy: Sacred Cavern Oracle** คือแอปพลิเคชันจำลองพิธีกรรมดูดวงการเสี่ยงทายโบราณ (Cleromancy) ผู้ใช้สามารถตั้งจิตอธิษฐาน พิมพ์คำถามที่คาดหวังในใจ (เรื่องความรัก, การงาน, การเงิน, อนาคต, หรือทางแยกชีวิต) และเลือกประกอบพิธี:
1. **Astragalomancy (ลูกเต๋าพยากรณ์ 3 กษัตริย์)**: ลูกเต๋าแกะสลักทองเหลืองโบราณ 3 ลูก ที่แสดงแต้มศักดิ์สิทธิ์ ทิศทาง และผลรวมโชคชะตา
2. **Elder Futhark Rune Cast (เหวี่ยงหินรูนสลักอักขระ 3 ภพ)**: หินออบซิเดียนสลักอักษรรูนเรืองแสงสีทอง 3 ก้อน (อดีต/รากเหง้า, ปัจจุบัน/อุปสรรค, อนาคต/ผลลัพธ์)
3. **Grand Cleromancy Ritual (พิธีมหาสังเคราะห์)**: รวมทั้งลูกเต๋าและหินรูนลงบนผืนผ้าพยากรณ์กำมะหยี่สีดำขลิบทอง

### Target Audience & Key Value
- ผู้ที่หลงใหลในศาสตร์พยากรณ์โบราณ, ไพ่ทาโรต์, และการเสี่ยงทายเชิงจิตวิญญาณ
- ได้สัมผัสประสบการณ์เสมือนจริงที่มีความขลัง ทั้งแอนิเมชันการหมุน/กลิ้งตกกระทบ เสียงสั่นกระดิ่ง/เสียงก้อนหินกระทบ (Web Audio API) และแสงเทียนที่วูบไหว
- ได้รับคำทำนายที่เฉพาะเจาะจงกับคำถามของตนเอง ไม่ใช่คำทำนายซ้ำๆ แบบสุ่มสคริปต์ตายตัว

## 2. User Experience & Visual Design

### Key User Flows
1. **Sacred Altar (หน้าแท่นบูชาหลัก)**:
   - ต้อนรับผู้ใช้ด้วยบรรยากาศถ้ำหิน เปลวเทียนสลัวรอบแท่นบูชา และวงแหวนเวทมนตร์สีทอง
   - ช่องรับคำถามจิตอธิษฐาน: "ตั้งจิตถามสิ่งที่ท่านต้องการหยั่งรู้..." พร้อมปุ่มเลือกหมวดหมู่ (ความรัก, การงาน/การเงิน, โชคชะตาทั่วไป, การตัดสินใจ)
   - แผงเลือกอุปกรณ์: สลับระหว่าง "ลูกเต๋าพยากรณ์โบราณ", "หินรูนศักดิ์สิทธิ์", หรือ "พิธีกรรมร่วม"
2. **The Casting Ritual (พิธีกรรมเสี่ยงทาย)**:
   - ผู้ใช้กดปุ่ม "เขย่าและเหวี่ยงอุปกรณ์ (Cast)" หรือคลิกสั่นกระบอกทองเหลือง
   - เกิดเอฟเฟกต์ฟิสิกส์ 3D CSS / Canvas: ลูกเต๋าและหินรูนหมุนเคว้งและตกลงบนแท่นหินพร้อมเสียงกระทบกังวาน (Synthesized Mystic Audio Chime & Stone Thud)
   - อุปกรณ์หยุดนิ่งและเปล่งแสงออร่าสีทอง เผยแต้มและอักษรรูนที่ถูกเลือก
3. **The Revelation & AI Oracle (การคลี่คลายคำทำนาย)**:
   - การแปลผลเบื้องต้นทันทีตามศาสตร์โบราณ (ความหมายของรูน, ผลรวมลูกเต๋า, ธาตุประจำทิศ)
   - การวิเคราะห์เจาะลึกสดโดย Gemini AI ที่นำคำถามของผู้ใช้มาผูกโยงกับสัญลักษณ์ที่ได้ ให้คำแนะนำและข้อเตือนสติอย่างสุขุมลุ่มลึก
4. **Grimoire Chronicle (คลังประวัติคำทำนาย)**:
   - บันทึกประวัติการดูดวงทุกครั้งลงใน Local Storage ผู้ใช้สามารถย้อนดูผลลัพธ์, กรองตามหมวดหมู่, และกดคัดลอกหรือแชร์การ์ดคำทำนายสวยงามได้

### Visual Identity & Theme
- **Aesthetic Direction**: Sacred Cavern Mysticism (ถ้ำหินศักดิ์สิทธิ์ มนต์ขลัง ลึกลับ สงบ และประณีต)
- **Color Palette (60-30-10 Disciplined Palette)**:
  - Canvas (60%): `#090A0F` (Dark Cosmic Obsidian) ผสานเงาถ้ำหิน `#0F111A`
  - Structural Surfaces (30%): แผ่นหินชนวน `#161926` ขอบเส้นทองบางเฉียบ `rgba(212, 175, 55, 0.2)` และผืนผ้ากำมะหยี่ `#11131E`
  - Focal Accents (10%): ประกายทองอำพันบริสุทธิ์ `#D4AF37`, `#F59E0B`, และแสงออร่าเวทมนตร์ `#FDE68A`
- **Typography & Hierarchy**:
  - หัวเรื่อง & ชื่อสัญลักษณ์: `Cinzel` / `Playfair Display` ฟอนต์หรูหราทรงคุณค่าโบราณ
  - เนื้อหา & คำพยากรณ์ภาษาไทย: `Prompt` / `Plus Jakarta Sans` อ่านง่าย สบายตา คมชัดทุกขนาดหน้าจอ
- **Interactive Feedback & Motion**:
  - ละอองประกายทอง (Gold dust ember particles) ลอยเอื่อยๆ เบื้องหลัง
  - การสั่นสะเทือนและการกลิ้งของลูกเต๋า/หินรูน (Dynamic 3D Rotation & Spring settling)
  - แท่งเทียน 3 เล่มรอบแท่นบูชาที่มีแสงไฟริบหรี่แบบมีชีวิต

## 3. Key Product Decisions & Trade-Offs

- **การประมวลผล AI ร่วมกับฐานข้อมูลออฟไลน์**:
  - *แนวทาง*: สร้างฐานข้อมูลความหมายรูนทั้ง 24 ตัว (เช่น Fehu, Ansuz, Raidho, Sowilo) และแต้มลูกเต๋า 3-18 แบบดั้งเดิมไว้ในเครื่อง เพื่อให้ระบบแสดงผลทันที จากนั้นเรียกใช้ Gemini API ผ่าน Server Proxy `/api/divine` เพื่อสังเคราะห์คำทำนายเจาะลึก
  - *เหตุผล*: ผู้ใช้ไม่ต้องรอนาน และหากไม่มีอินเทอร์เน็ตหรือโควต้าหมด แอปยังคงทำงานได้อย่างสมบูรณ์แบบ
- **การจำลองฟิสิกส์การเหวี่ยงและทอย**:
  - *แนวทาง*: ใช้ CSS 3D Transforms ร่วมกับ Canvas Particle System และ Spring Physics ของ Framer Motion / Motion
  - *เหตุผล*: ประสิทธิภาพสูง โหลดเร็ว รองรับทุกอุปกรณ์ทั้งมือถือและเดสก์ท็อปโดยไม่กินทรัพยากรเครื่อง
- **การจัดเก็บข้อมูลประวัติ (Grimoire History)**:
  - *แนวทาง*: จัดเก็บใน Client `localStorage` อย่างเป็นระบบ พร้อมปุ่ม Export / Clear
  - *เหตุผล*: ให้ความเป็นส่วนตัวสูงสุดแก่คำถามดวงชะตาของผู้ใช้ โดยไม่ต้องบังคับสมัครบัญชี

### Server API Implementation
- เพิ่มไฟล์ `server.ts` ด้วย Express ให้บริการ `/api/divine`
- เรียกใช้ `@google/genai` รุ่นล่าสุด พร้อม `gemini-3.8-flash` และ `User-Agent: 'aistudio-build'`
- พรอมต์วิเคราะห์ดวงชะตาเชิงปรัชญา ชี้แนะแนวทาง และให้พลังใจแก่ผู้ถามอย่างลึกซึ้ง

### Verification Plan
1. ตรวจสอบการทอยลูกเต๋า 3 ลูก และการสุ่มหินรูน 3 ก้อน พร้อมแอนิเมชันและเอฟเฟกต์เสียง
2. ทดสอบการส่งคำถามไปยัง `/api/divine` และรับคำทำนายที่ตรงประเด็น
3. ทดสอบการบันทึกประวัติการดูดวง การลบประวัติ และการเรียกดูผลเก่า
4. รัน `compile_applet` เพื่อยืนยันว่าการคอมไพล์สำเร็จสมบูรณ์
